## A few things I've built

- **Zender — automated publishing platform** — bulk message delivery to Telegram and WhatsApp groups using NestJS + GramJS + BullMQ + Redis + TypeORM, with real-time chat sync over Socket.IO
- **Multi-agent AI backend** — a Python-based multi-agent system on OpenRouter, with RAG via pgvector, context compaction, and file/terminal tools
- **Ops Intelligence** — a portfolio SaaS for small businesses: NestJS/TypeORM API, Django admin panel, MongoDB for event logs, Elasticsearch search, a CrewAI/LangGraph agent for natural-language business queries, and n8n wiring up WhatsApp/Telegram
- **USACAR** — a car marketplace platform: NestJS backend split into buyer-facing and admin modules, slot-based appointment scheduling with Redis caching, and a React frontend with an admin dashboard
- **SaaS landing page generator** — NestJS CRM backend + Next.js frontend + a standalone Template Service, with a block-renderer system so new templates ship with zero frontend code changes
- **Django 5.2 migration** — freelance work modernizing a media-streaming platform (Picta/GestorMedias), including Elasticsearch and Celery upgrades
